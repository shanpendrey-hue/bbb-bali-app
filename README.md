# B.B.B Bali App — Nicolle's 50th

A mobile-first installable web app (PWA) for **Nicolle's 50th — The Big Bali Bash, Bali 2027**.

## What's in version 1
- Branded mobile homepage
- Countdown to 25 January 2027
- Full itinerary shell
- Big Bali Bash event page
- Great Aussie Recovery page
- Finger food, buffet and kids menus
- Booking / dietary form (saved locally on each device for now)
- Bali guide
- Villa information page
- Contact page
- Installable PWA manifest + service worker

## How to put this into your GitHub folder
1. Extract this ZIP.
2. Copy **all files inside the extracted folder** into your existing `bbb-bali-app` folder.
3. If Windows asks whether to replace `README.md`, choose **Replace**.
4. Do **not** delete the existing `.git` folder.
5. Open GitHub Desktop. You should now see the new files under **Changes**.
6. In Summary type: `Build BBB starter app`
7. Click **Commit to main**.
8. Click **Push origin**.

## Preview locally
The easiest preview later is through Vercel once the repo is connected. This project is plain HTML/CSS/JS so it does not require Node.js to deploy.
