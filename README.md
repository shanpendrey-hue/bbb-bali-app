# Nicolle's 50th — B.B.B Bali 2027

Rebuilt guest-facing PWA using the supplied B.B.B visual system natively (not pasted brand boards).

## Deploy
Upload all files/folders in this directory to the GitHub repo root. Vercel will redeploy automatically if connected.

## Demo limitations
Shared cloud photo storage, shared massage inventory, confirmation email, push notifications, flight-status API and Stripe checkout require production backend/services and are intentionally not faked in this front-end build.
